PSX Forest

Documentation

Every prop is a prefab in Assets/PSXForest/Prefabs/ (PF_<prop>): drag it into a scene. 1 unit = 1 m; a prop's pivot
is on the floor (or, for a wall prop, on the wall) it rests against. Each part has a box collider.

Look
Every prefab uses Materials/, which use the shader PSXForest/PSX Unlit: the texture times the baked
vertex shading, unlit, with the PS1's vertex snap (Vertex Snap: rows on screen, 0 = off) and Unity's fog.
Affine Texture Warp (0 as shipped, up to 1) gives the PS1's swimming textures, most on big faces seen close.
Render pipelines: Built-in and URP: the materials use the pack's one-pass unlit shader (vertex snap, fog, and an affine texture warp to turn on), which both render. Not HDRP.

Animations
A prop with moving parts has an Animation component with its clips; nothing plays on its own:
    GetComponent<Animation>().Play("open");
Demo/L_Demo.unity circles the props and plays every animation in turn (Scripts/PropsDemo.cs).
Demo/L_Level.unity is a level of 988 of them to walk (Scripts/LevelWalker.cs): WASD or the
arrows and the mouse, Shift runs, E uses what is in front of you, Esc frees the mouse.

Pickups
An item to take, a save point or storage has Scripts/Pickup.cs on its prefab, set up in the inspector: its
kind (Item, Save, Storage), the item it gives and how many, its title and text, its reveal (the clip the
inspect view plays) and, for a save, what it takes (an ink ribbon); UnityEvents for what it does (onPicked,
onSaved, onOpened, onRefused, onUsed). An item glints until it is taken.
    key.Use(carried);                       // carried: the player's items, a List<string>; the key goes in
    typewriter.Use(carried);                // takes an ink_ribbon, saves
Scripts/Inspect.cs holds a prop up over the game to turn and read, E playing its reveal, Esc putting it away:
    inspect.Open(diary.gameObject);

Machines
A prop that works (its kind is in the list below) has Scripts/Machine.cs on its prefab, set up in the
inspector: its kind (what a use does: Switch, Button, Turn, Slot, Keypad, Panel, Item, Powered, Gauge),
the machines it needs to be powered, and UnityEvents for what it does (onSwitched, onLive, onRefused,
onUsed, onKeyed, onPicked). Machine.cs's comments say what each kind does.
    lever.Use(carried);                     // the player's use; carried: the items they hold
    keypad.Use(carried, "keypad_key_4");    // a key: the part they point at
    door.needs = new[] { lever };           // the door is powered while the lever is on

Textures: T_atlas.png 2048x2048, T_dirt.png 128x128, T_forest_floor.png 128x128, T_grass.png 128x128, T_grass_dry.png 128x128, T_moss.png 128x128, T_mud.png 128x128, point filtered, no mipmaps.
Icons/: an inventory icon per prop, T_<prop>, imported as a UI sprite.
